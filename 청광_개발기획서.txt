2. 서비스 개요
2.1 한 줄 정의
청광은 청소에 특화된 역경매 매칭 플랫폼이다. 의뢰인은 한 번의 요청으로 복수의 청명으로부터 견적을 받아 비교·선택하고, 청명은 자신의 전문 영역·지역에 맞는 고객을 시간 낭비 없이 수주한다.
2.2 배경 및 문제 정의
이해관계자
현재의 문제
청광이 해결하는 방법
의뢰인 (가정·사무실·상가)
· 청소 업체 정보가 파편화되어 비교가 어려움
· 가격·품질·응답 속도 예측 불가
· 불투명한 견적, 분쟁 시 책임소재 불명
· 표준화된 요청 양식으로 복수 견적 동시 수신
· 재계약률·응답시간·완료건수 3대 지표 공개
· 상태 머신 기반 거래 흐름 + 배상보험 표기
청명 (청소 전문가)
· 신규 고객 유입 채널 부족, 광고 의존도 높음
· 비전문 문의·허수 요청 응대 피로
· 포트폴리오·신뢰를 보여줄 공간 없음
· 매칭 알고리즘이 지역·전문성 기준으로 필터링
· 견적서 작성 도구 + 표준 가격 가이드
· Before/After 포트폴리오 · 인증 배지
2.3 핵심 가치 제안 (Value Proposition)
	•	신뢰 가시화 — 재계약률 · 평균 응답시간 · 완료 작업 수의 3대 지표를 전면 표기
	•	역경매 구조 — 의뢰인은 1회 요청으로 복수 견적을 비교, 청명은 조건 부합 고객만 응답
	•	증거 기반 마케팅 — Before/After 사진을 리뷰보다 상위에 배치 (Show, Don’t Tell)
	•	거래 신체기관 = 채팅 — 결제·방문예약·리뷰요청을 모두 채팅 스레드 하단 액션으로 통합
	•	상태 머신 기반 거래 관리 — 요청 → 견적수신 → 협의진행 → 거래완료 4단계 일원화
2.4 경쟁·레퍼런스 분석
포괄 긱매칭 플랫폼(숨고)을 레퍼런스로 하되, 청광은 청소 1개 도메인만 다루므로 다음 방향으로 특화한다.

4. 제품 범위 및 단계별 출시 전략
4.1 단계별 로드맵 개요
청광은 본격 매칭 플랫폼을 일시에 출시하지 않고, 운영 리스크·인력 상황을 고려하여 세 단계로 구분하여 추진한다. Phase 0의 매출·운영 지표를 달성했을 때 Phase 1에 착수한다.

	•	공통 크로스 로직 (그룹 X) — 거래 상태 머신·알림·매칭 가중치·임시저장·결제 정책

6.4 그룹 B — 의뢰인 · 견적 요청·관리

	•	B1~B4 · 견적 요청 마법사 — 청소 유형 · 유형별 조건 분기 · 다음 버튼 상태 제어 · 요청 완료 애니메이션

	•	B7 · 가격 범위 표시 (3개 청명 · 22~32만원) · B8 · 비교하기 CTA

Flow A · 역경매 견적 요청 → 거래 완료 (메인)

청명찾기 → 필터 → 리스트/지도 → 청명 상세 → 채팅 문의 → 협의 후 정식 견적 요청 또는 바로 예약

앱 오픈 → 홈 오늘의 할 일 카드 → 받은견적 상세 또는 채팅 스레드로 직행
Flow D · 청명 요청 수주
받은요청 스택 → 좌/우 스와이프 → 조건 확인 → 견적서 작성(슬라이더·스텝퍼·옵션) → 전송

	•	청명 인증은 2단계: 신원확인 → 배상보험 가입 증빙. 프로필 공개 전 필수
	•	배상보험 미가입 청명은 카드 배경·Chip에서 즉시 식별되도록 시각 구분 (danger 톤)
	•	Phase 0의 위생 안심 배지는 청광 실제 고객만 부여, Firestore 규칙상 클라이언트가 변경 불가 (운영자 수동)
