## 화면 상세

### 5. 와이어프레임 & 기능 디스크립션 — 로그인 페이지

**PATH**: 진입 > 로그인

**메인 목업**: (wireframe_svg fallback)

#### Function Description

| 1 | **이메일 인풋 박스** |
|---|---|
|  | • 텍스트 입력 제한 — 320자 초과 입력 막음 |
|  | • 주소 앞자리 64자 + @ + 도메인 255자 (최대 320자) |
|  | • 영문/숫자/일부 기호('_'(언더바), '.'(마침표)) 사용 가능 |
|  | • 이메일 형식 유효성 체크: XXX@XXX.XXX |

| 2 | **비밀번호 인풋 박스** |
|---|---|
|  | • 텍스트 입력 제한 — 8자 이상의 문자/숫자/기호 입력 가능 |
|  | • 비밀번호 표시 버튼 — 입력 시 실시간 숨김 처리, 표시 버튼 클릭 시 노출 |
|  | • Cancel 버튼은 비밀번호 표시 버튼의 좌측에 위치 |

#### Button Description

| A | **[로그인] Submit 버튼** |
|---|---|
|  | • 이메일 + 비밀번호 인풋 박스 유효 시 활성화 |
|  | • 활성화 클릭 시 — 데이터 유효성 체크 후 Invalid면 Validation message 표시 |
|  | • 로그인 정보 10회 불일치 시 계정 잠금 + 안내 메일 발송 |

| B | **비밀번호 찾기 텍스트 링크** |
|---|---|
|  | • 비밀번호 재설정 페이지로 이동 |

| C | **[회원가입] 버튼 링크** |
|---|---|
|  | • 회원가입 페이지로 이동 |

#### 컴포넌트 상태 변형

- 기본 입력 박스
- 포커스 인 상태
- 이메일 입력 시
- 입력 텍스트 숨김 시
- 포커스 아웃 - Valid
- 포커스 아웃 - Invalid
