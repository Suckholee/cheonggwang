# 산출물 포맷 명세

스토리보드 JSON 한 벌에서 생성되는 산출물의 표준.

---

## 1. PPTX (메인 산출물)

`scripts/build_storyboard_pptx.py`가 만든다.

### 슬라이드 순서

| # | 슬라이드 | 데이터 소스 |
|---|----------|-------------|
| 1 | 표지 | `meta` |
| 2 | 개정 이력 표 | `revision_history` |
| 3 | IA 흐름도 | `ia` 전체 |
| 4 ~ N | 화면별 상세 (1화면 = 1슬라이드) | `screens[]` |

화면이 많아 1슬라이드에 다 안 들어가는 경우(상태 변형 10개 이상 + Function Description 5개 이상 등)는 자동으로 2슬라이드로 분리하고 헤더에 `(2/2)` 표시.

### 슬라이드 1 — 표지

레이아웃:
```
                   {meta.service}
              스토리보드 (화면 정의서)
              ───────────────────

           v{meta.version} · {meta.created_at}
                 작성자: {meta.author}
              {meta.client ? '클라이언트: ' + meta.client : ''}
                플랫폼: {meta.platform 한글}
                 용도: {meta.purpose}
```

폰트: 제목 40pt 굵게, 부제 18pt, 메타 정보 12pt 회색.

### 슬라이드 2 — 개정 이력

```
                   개정 이력 (Revision History)

┌─────────┬─────────────┬─────────┬───────────────────────────┐
│ Version │ Date        │ Author  │ Summary                   │
├─────────┼─────────────┼─────────┼───────────────────────────┤
│ 0.1     │ 2026-04-20  │ OOO     │ 초안 작성                  │
│ 0.2     │ 2026-04-25  │ OOO     │ 로그인 화면 상세 추가       │
└─────────┴─────────────┴─────────┴───────────────────────────┘
```

표 폭은 슬라이드 가로 80% 사용, 가운데 정렬.

### 슬라이드 3 — IA 흐름도

`generate_ia_diagram.py`가 만든 IA를 슬라이드 본문에 박는다. 두 모드:

- `--ia-render image`: SVG → PNG 변환 후 이미지로 삽입
- `--ia-render shapes` (기본): 박스/화살표를 PPTX 도형으로 직접 그려 편집 가능하게

상단 우측에 카테고리 색상 범례. 슬라이드 좌상단에 작은 "IA / Site Map" 라벨.

### 슬라이드 4~N — 화면 상세

`screen_detail_spec.md`의 5분할 레이아웃을 그대로 구현. 각 영역은 `python-pptx`의 `add_textbox`, `add_shape`, `add_table`, `add_picture`로 배치.

## 2. Markdown (보조 산출물)

`scripts/build_markdown.py`가 만든다.

### 표준 템플릿

```markdown
# {meta.title}

> **Service**: {meta.service} · **Platform**: {meta.platform}
> **Version**: {meta.version} · **Created**: {meta.created_at}
> **Author**: {meta.author} · **Purpose**: {meta.purpose}

## 개정 이력

| Version | Date | Author | Summary |
|---------|------|--------|---------|
| 0.1 | 2026-04-20 | OOO | 초안 작성 |

## IA / Site Map

### 카테고리

- 🟧 **진입/계정** — auth
- 🟨 **메인** — main
- ⬜ **부가기능** — extra
- ⬜ **설정·관리** — config

### 박스 트리

- **B01_스플래시** [auth]
- **B02_튜토리얼** [auth]
- **B03_로그인** [auth]
  - 1. 아이디/비밀번호 로그인
  - 2. 간편 로그인
  - 3. 핀번호 로그인
- **B05_홈메인** [main]
  - 1. 알림
  - 2. 사용 내역
    - 지갑 QR코드
  - 3. 보내기
    - 보안비밀번호 등록
    - 이체정보입력 — QR코드 검색 / 회원 검색
    - 이체완료/확인
  - 🔶 ※ MVP 때 스토어가 없다면 ... ← open_question

### 흐름

```
B01_스플래시 → B02_튜토리얼 → B03_로그인 → B05_홈메인
                                ↓ (비번 분실)
                              B04_비밀번호찾기
```

## 화면 상세

### 5. 와이어프레임 & 기능 디스크립션 — 로그인 페이지

**PATH**: 진입 > 로그인

**메인 목업**: ![login](assets/uploads/login_screen.png)

#### Function Description

| ① | **이메일 인풋 박스** |
|---|----------------------|
|   | • 텍스트 입력 제한 |
|   | • 320자 초과 입력 막음 |
|   | • 영문/숫자/일부 기호 사용 가능 |
|   | • 이메일 형식 유효성 체크: XXX@XXX.XXX |

| ② | **비밀번호 인풋 박스** |
|---|------------------------|
|   | • 텍스트 입력 제한 — 8자 이상 |
|   | • 비밀번호 표시 버튼 |

#### Button Description

| Ⓐ | **[로그인] Submit 버튼** |
|---|--------------------------|
|   | • 이메일 + 비밀번호 유효 시 활성화 |
|   | • 활성화 시 검증 후 Invalid면 메시지 표시 |
|   | • 10회 불일치 시 계정 잠금 |

#### 컴포넌트 상태 변형

- 기본 입력 박스
- 포커스 인 상태
- 이메일 입력 시
- 입력 텍스트 숨김 시
- 포커스 아웃 - Valid
- 포커스 아웃 - Invalid

#### Validation 메시지

| 체크시점 | 조건 | 메시지 | 노출 유형 |
|---------|------|--------|-----------|
| 2 | 이메일 형식 오류 | 이메일 주소를 확인해주세요. | 인풋박스 하단 문구 |
| 4 | 아이디/비밀번호 불일치 | 이메일 또는 비밀번호를 확인해주세요. | 비밀번호 인풋 박스 하단 |
| 4 | 계정 10회 불일치 | ▶ 계정 잠금 안내 / 로그인 정보 10회... / [확인] | 디자인 팝업 |
| 4 | 사용 기기 변경 | ▶ 기기 변경 안내 / [아니요][예, 변경합니다] | 디자인 팝업 |
```

규칙:
- `auto_filled: true` 항목은 앞에 `🔶`
- 화살표 흐름 다이어그램은 단순 `→` `↓` 텍스트
- 화면 사이 구분 `---`

## 3. SVG IA 다이어그램

`scripts/generate_ia_diagram.py` 출력. 자세한 사양은 `ia_diagram_spec.md`.

---

## 4. SVG 와이어프레임 fallback

이미지 업로드가 없는 화면용. 자세한 사양은 (이전 와이어프레임 docs와 동일):
- 모바일: 360×720 viewBox, 회색조 단색
- 컴포넌트 타입별 표준 도식

## 산출 파일 정리

빌드 후 생성되는 파일들:

```
<output_dir>/
├── 스토리보드.pptx               ← 메인 산출물
├── 스토리보드.md                 ← 보조 산출물 (옵션)
├── assets/
│   ├── ia.svg                   ← IA 다이어그램 원본
│   ├── ia.png                   ← PPTX 삽입용
│   ├── uploads/                 ← 사용자 업로드 화면 시안 원본
│   │   └── login_screen.png
│   └── wireframes/              ← fallback wireframe들
│       └── B05_홈메인.svg
└── storyboard.json              ← 단일 진실 공급원 (재빌드용)
```
