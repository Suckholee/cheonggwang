# 화면 상세 페이지 표준 (5분할 레이아웃)

보내주신 두 번째 이미지("5. 와이어프레임 & 기능 디스크립션")의 레이아웃을 PPTX 슬라이드 마스터로 표준화한 것.

---

## 슬라이드 캔버스

- 16:9 비율 가정 (가로 13.33in × 세로 7.5in = 1920×1080 px @ 144dpi)
- 외부 여백: 좌우상하 각 0.4in
- 모든 좌표는 inch 단위로 명세

---

## 헤더

```
┌───────────────────────────────────────────────────────────────┐
│  5. 와이어프레임 & 기능 디스크립션                                │ ← 22pt 굵게, 좌측 정렬
│                                                                │
│  ┌─────┬─────────────────────┐                                │
│  │PATH │ 로그인 페이지         │ ← PATH 박스 (높이 0.35in)       │
│  └─────┴─────────────────────┘                                │
│                                                                │
└───────────────────────────────────────────────────────────────┘
```

- 섹션 제목: `{section_no}. {section_title}` (없으면 화면 title만)
- PATH 박스:
  - 좌측 셀(폭 0.8in): 회색(#6B7280) 채움 + 흰 글씨 "PATH"
  - 우측 셀(폭 6in): 흰 배경 + 검정 글씨로 path 값
- 헤더 영역 총 높이: 1.0in

### 좌측 — 컴포넌트 상태 변형 stack

- 좌측 컬럼 폭: 2.4in
- 시작 y: 1.2in (헤더 아래)
- 각 상태 블록:
  - 라벨 (상태 이름): 12pt 굵게 (#3B82F6 같은 강조색)
  - 시각 미니어처: SVG로 그린 컴포넌트 표현 (높이 0.6in)
  - 블록 사이 간격: 0.3in
- 상태가 6개를 넘어가면 폰트와 미니어처 비율을 자동 축소

### 중앙 — 메인 목업 이미지

- 중앙 컬럼 시작 x: 2.9in, 폭: 5.5in
- 시작 y: 1.2in, 높이: 5.5in (남는 공간 가득)
- `main_mockup.kind == "image"`이면 PIL로 비율 유지하며 박스 안에 fit
- `main_mockup.kind == "wireframe_svg"`이면 SVG 와이어프레임을 PNG로 변환해 삽입 (또는 PPT 도형으로 직접)
- **annotation 마커 오버레이**:
  - `kind == "number"`: 빨간색(#DC2626) 채움 원, 흰 글씨 숫자 14pt
  - `kind == "letter"`: 파랑(#3B82F6) 채움 원, 흰 글씨 알파벳 14pt
  - 위치는 `{x: 0~1, y: 0~1}` 정규화 좌표 → 이미지 박스 안에서 비율 환산
  - 마커 직경: 0.3in

### 우측 — 명세 영역

우측 컬럼 시작 x: 8.6in, 폭: 4.6in. 위에서 아래로 3개 섹션:

#### Function Description (우상)

```
┌─────────────────────────────────────────┐
│ Function Description                     │ ← 헤더 (회색 채움, 흰 글씨)
├──┬──────────────────────────────────────┤
│ 1│ • 이메일 인풋 박스                      │
│  │   - 텍스트 입력 제한                    │
│  │   - 320자 초과 입력 막음                │
│  │   ...                                  │
├──┼──────────────────────────────────────┤
│ 2│ • 비밀번호 인풋 박스                    │
│  │   ...                                  │
└──┴──────────────────────────────────────┘
```

- 헤더 행: 높이 0.3in, 진회색(#6B7280) 채움
- 마커 셀: 폭 0.4in, 가운데 정렬, 굵게
- 본문 셀: lines 배열을 불릿으로 렌더 (들여쓰기 처리)
- 폰트: 마커 12pt 굵게, 본문 10pt
- 행 사이 1px 회색 구분선

#### Button Description (우중)

Function Description과 같은 표 구조. 헤더만 "Button Description"으로.

#### Validation 메시지 표 (우하)

```
┌──┬──────────┬─────────────────────┬──────────┐
│체│ 조건      │ 메시지               │ 노출유형  │
│크│           │                     │          │
│시│           │                     │          │
│점│           │                     │          │
├──┼──────────┼─────────────────────┼──────────┤
│ 2│ 이메일... │ 이메일 주소를...      │ 인풋박스 │
│  │           │                     │ 하단 문구 │
├──┼──────────┼─────────────────────┼──────────┤
│ 4│ 계정 10회│ ▶ 계정 잠금 안내       │ 디자인   │
│  │ 불일치   │   로그인 정보 10회... │ 팝업     │
│  │          │   [확인]             │          │
└──┴──────────┴─────────────────────┴──────────┘
```

- 컬럼: 체크시점(0.4in) / 조건(1.2in) / 메시지(2in) / 노출유형(0.9in)
- 헤더 행 높이 0.3in, 회색(#9CA3AF) 채움
- `message_title` + `message_buttons`가 있으면 메시지 셀 안에 다음 형태로:
  ```
  ▶ {message_title}
    {message}
    [버튼1] [버튼2]
  ```

## 박스/표 공통 스타일

- 외곽 테두리: 1px #94A3B8
- 헤더 row 채움: #6B7280 또는 #9CA3AF (의미별 구분)
- 본문 row 교차 채움 (zebra): 짝수 #F8FAFC, 홀수 #FFFFFF (선택, 가독성용)
- 폰트: 한글 본문 10pt 명조 또는 sans-serif (시스템 기본), 헤더 12pt 굵게

---

## auto_filled / open_question 강조

- 슬라이드 어디든 `auto_filled: true`인 항목 앞에는 **〔자동〕** 회색 prefix
- 화면 단위 `open_questions`가 있으면 슬라이드 우하단에 작은 빨간 박스로 표시:
  ```
  ※ open: 비밀번호 정책 8자 vs 10자 결정 필요
  ※ open: 소셜 로그인 자동 가입 여부?
  ```

---

## fallback (이미지 없을 때)

`main_mockup.kind == "wireframe_svg"`이면 `screen.main_mockup.wireframe_layout`을 사용해 `scripts/generate_wireframe.py`가 그린 SVG를 중앙에 박는다. 이 경우 어노테이션 마커도 wireframe 컴포넌트에 매핑해 적절히 위치시킨다.
