# IA 다이어그램 표준

`scripts/generate_ia_diagram.py`가 따르는 시각 규약.

---

## 캔버스

- 가로 1920 / 세로 1080 (16:9, 슬라이드 1장 가득 채움)
- 좌측 16px 여백, 상단 60px(범례·제목용 여유)

---

## 박스 (노드) 사양

```
┌───────────────────────────────┐  ← 헤더 (높이 28, 카테고리 색상 채움, 흰 글씨 14pt 굵게)
│  홈메인 (월렛)                 │
├───────────────────────────────┤
│  1  알림                      │  ← 1차 항목 (12pt)
│  2  사용 내역                  │
│     • 지갑 QR코드              │  ← 2차 항목 (10pt 회색)
│  3  보내기                    │
│     • 보안비밀번호 등록         │
│     • 이체정보입력 — QR코드 검색 │
│  ── (생략 마커 가능) ──         │  ← 항목 너무 많을 때
└───────────────────────────────┘
  ← 점선 테두리는 auto_filled
```

### 사이즈

| 항목 | 값 |
|------|-----|
| 박스 폭 | 220px (가변, 텍스트 길이 기준 자동) |
| 박스 최소 높이 | 80px |
| 한 줄 항목 높이 | 22px |
| 한 줄 sub-item 높이 | 18px |
| 헤더 높이 | 28px |
| 박스 간 가로 간격 | 60px |
| 박스 간 세로 간격 | 40px |
| 라운드 코너 | rx=4 |

### 카테고리 색상

`ia.categories[].color`를 그대로 헤더 fill로. 글자는 무조건 #FFFFFF (대비 보장).

기본 팔레트(사용자가 직접 정의 안 했을 때):

```
auth    #F59E0B  (오렌지)
main    #FACC15  (옐로우)
extra   #9CA3AF  (그레이)
config  #94A3B8  (라이트 그레이)
admin   #DC2626  (레드)
billing #2563EB  (블루)
content #14B8A6  (틸)
```

박스 본문 영역 fill: `#FFFFFF`. 테두리: `#94A3B8` (1px). `auto_filled: true`이면 테두리를 dashed.

### 빨간 메모 (open_questions)

박스 안 마지막 항목들 아래에 빨간 텍스트(#DC2626, 10pt) 박스로 따로 그린다. 머리에 `※` 또는 `•` 마커.

```
※ MVP 때 스토어가 없다면 스토어 대신
  마이너 관리 페이지를 위치?
```

3줄 넘으면 자동 줄바꿈, `…` 으로 잘리지 않도록 박스 높이 자동 확장.

## 화살표 (connections)

| `style` | 두께 | 색상 | 비고 |
|---------|------|------|------|
| `primary` | 2px | `#1F2937` | 메인 흐름 |
| `secondary` | 1px | `#6B7280` | 보조 흐름 (default) |
| `dashed` | 1px dashed | `#6B7280` | 조건부/예외 흐름 |

화살촉은 단순 ▶ (path `M-8,-4 L0,0 L-8,4 z` 같은 폴리곤).

### 라우팅 규칙

자동 라우팅:
1. `from`이 `to`의 좌측에 있으면 → 우측 변에서 출발해 좌측 변으로 (직선 또는 L자)
2. `from`이 `to`의 위에 있으면 → 하단 변에서 출발해 상단 변으로
3. 같은 행이면 가운데를 지나도록 약간 우회 (인접 박스 통과 회피)

label은 화살표 중간에 흰 배경 박스 + 10pt 텍스트로 얹는다.

## 그리드 배치 (자동)

박스의 `row`/`col`이 명시되지 않으면 자동 배치:

1. **카테고리별로 col 그룹**: 같은 카테고리는 같은 col에 세로로 쌓는다.
2. **연결 깊이로 col 추정**: 진입점(아무 connection의 `to`로 등장하지 않는 박스)은 col=1, 연결 따라 col 증가.
3. **충돌 시 row 자동 증가**.

사용자가 일부만 명시하면 그것만 우선시하고 나머지는 자동.

## 범례 (Legend)

우상단에 카테고리 색상 범례를 작은 박스로:

```
┌─────────────────────────────┐
│ ■ 진입/계정     ■ 메인        │
│ ■ 부가기능      ■ 설정·관리    │
└─────────────────────────────┘
```

`legend_position`이 `top_right` (default), `top_left`, `bottom_right` 중 하나.

## 출력 형식

- 기본 출력: `assets/ia.svg`
- PPTX 빌더가 svg를 PIL로 png로 변환해 슬라이드에 삽입 (cairosvg 의존성 회피, 단순 case는 PIL+ElementTree로 직접 픽셀화하거나, 슬라이드 위에 도형으로 직접 그리는 옵션도 제공).

PPTX 슬라이드에 박는 방법은 두 가지를 지원:

1. **이미지로 삽입** (간단·완벽한 모양 보존, 편집 불가)
2. **PPTX 도형으로 직접 그림** (편집 가능, 약간 단순화)

`build_storyboard_pptx.py --ia-render mode` 인자로 선택. 기본값: `shapes` (편집 가능 우선).
